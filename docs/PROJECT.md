## 0. 一句话定位

> **"为 Windows 重度用户打造的本地优先桌面抽屉柜：4 个高频数据模块 + 1 个永远在屏幕上的小窗口，能装就装下、能搜就搜到。"**

## 1. 需求市场

### 1.1 用户画像

| 维度 | 描述 |
|---|---|
| **操作系统** | Windows 10 / 11（仅此一个平台） |
| **人群** | 电脑前工作 6h+ 的"重度用户"：开发者 / 设计师 / 运营 / 学生 |
| **设备习惯** | 桌面常驻 5-15 个工具，开机自启一长串 |
| **隐私态度** | 对云端密码管理器有顾虑；愿意折腾但不要"麻烦" |
| **付费意愿** | 9.9 买断能接受；订阅抵触 |

### 1.2 五类核心痛点（来自 v2ex / 知乎 / 评测网站整理）

1. **桌面乱** - 文件/图标太多，懒得整理，又离不开
2. **找东西慢** - 系统搜索慢、不准；Everything 又是一个新工具
3. **重复操作多** - 同一段话/密码/路径每天敲几遍
4. **工具太多** - 装了 5-6 个小工具，互相打架，开机自启卡
5. **隐私焦虑** - 1Password / LastPass 服务器被攻击过

### 1.3 隐性需求（用户嘴上不说但在意）

- **"我想要一个，但不想再多装一个"** — 都希望一个工具解决 N 个问题
- **"想自定义又不想写代码"** — 配置要够灵活但门槛要够低
- **"数据必须在我自己电脑上"** — 隐私和可控性是底线
- **"别弹广告别收钱"** — 国产工具的"信任税"
- **"开箱即用，不要我配置"** — 自动化行为 > 手动模式选择

## 2. 竞品分析

### 2.1 矩阵定位

```
       重 (功能复杂) ▲
                      │   Raycast Pro
                      │   Alfred Powerpack
                      │   Quicker Pro
        ◀ 桌面中枢  ┼─────────────►  ← 抽屉柜 Wind-zp ✓
        (uTools)    │   抽屉柜 Wind-zp ✓
                      │   Yue Launcher
                      │   EcoPaste
       轻 (单一)     │   小黄条
                      │   Everything
                      └───────────────────► 广 (平台覆盖)
                          Win only     全平台
```

### 2.2 重点竞品逐个拆解

| 竞品 | 优势 | 短板 | 我们能蹭的 |
|---|---|---|---|
| **Raycast** | 苹果生态标杆，AI 强 | Win 仍 Beta，$8/月贵 | "窗口常驻 + 命令面板"思路 |
| **Alfred** | 稳定，老牌 | 界面老旧（2010 风） | workflow 的本地执行思路 |
| **Quicker** | 国内用户多 | 闭源，按月订阅，强制弹窗 | "鼠标手势 + 动作编排" 形态 |
| **uTools** | 国内生态最成熟 | 插件质量参差，加载要联网 | "一个窗口做 N 件事" 定位 |
| **EcoPaste** | Tauri 2 标杆，本地优先 | 只做剪贴板 | **Tauri 2 + Vue 3 + SQLite 技术栈直接抄** |
| **Yue Launcher** | 体积小，Win 体验好 | 单一启动器 | 360-480×480-720 窗口尺寸 |
| **小黄条** | 桌面常驻思路 | 只做待办 | 透明常驻 + 玻璃质感 |

### 2.3 差异化承诺（对用户的"我为什么装你"）

1. **桌面常驻 + 玻璃质感** — 区别于"打开才能用"的传统密码管理器
2. **本地优先 + 端到端加密** — 数据永远不离开电脑，区别于 1Password
3. **四合一** — 密码/软件/片段/临时一个抽屉搞定，区别于 5 个分散工具
4. **极简自动行为** — 贴边自动隐藏、15s 剪贴板自动清空、5min 自动锁；用户不用配置
5. **免费+9.9 双层定价** — 基础功能够用，付费解锁数量上限

### 2.4 我们明确**不**做的事

| 不做 | 原因 |
|---|---|
| ✗ 跨平台 | Win32 贴边隐藏是 Windows 专属，移植到 Mac 等于重写 |
| ✗ 云同步（v1.0） | 隐私敏感用户是核心人群，端到端加密云同步是 2.0 大工程 |
| ✗ 插件市场 | 维护成本高，对小工具是负担 |
| ✗ 取代系统启动器 | Alfred/Raycast 已经很强，没必要正面竞争 |
| ✗ AI 集成（v1.0） | 云依赖 + 你偏好"开箱即用"+"本地优先" |

## 3. 产品形态

### 3.1 窗口形态

| 形态 | 尺寸 | 触发 |
|---|---|---|
| **完整 widget** | 380×560（可在 360-480×480-720 内调） | Alt+Q / 点击托盘 |
| **极简图标列** | 56×320 | 标题栏 "◂" 按钮 |
| **隐藏态** | 贴边 6px 触角 | 闲置 350ms 后自动 |
| **唤回** | 自动弹回 | 鼠标靠近触角 12px |

### 3.2 五大模块职责

| 模块 | 职责 | 免费版上限 | 完整版（9.9） |
|---|---|---|---|
| **密码** | AES-256 加密存储，剪贴板 15s 自动清 | 10 条 | 不限 |
| **软件** | 扫描 StartMenu/Desktop/ProgramFiles，一键启动 | 10 个 | 不限 |
| **片段** | 文本片段（如正则、SQL 模板） | 5 条 | 不限 |
| **临时** | 草稿/便签，3 天自动清理 | 不限 | 不限（云同步？v2.0） |
| **置顶区** | 跨模块聚合最高频 5 项 | — | — |
| **常用** | 跨模块按 use_count 排序 | — | — |

> 临时区不设上限（用户不会因为草纸付费），其它三区通过数量限制制造"9.9 升级动机"。

### 3.3 全局快捷键

| 快捷键 | 行为 |
|---|---|
| `Alt+Q` | 弹窗 / 隐藏主窗口 |
| `Alt+L` | 立即锁定（清除内存密钥） |
| `Ctrl+Space` | （v1.0 不做）全局命令面板，未来扩展 |

## 4. 技术架构

### 4.1 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Tauri 2 + Vue 3 + TypeScript + Vite |
| 状态 | Pinia |
| 数据库 | SQLite (rusqlite) — 7 张表 |
| 加密 | AES-256-GCM + Argon2id（密钥派生） |
| 系统集成 | Win32 API（贴边隐藏、ShellExecuteW、SetWindowLongPtrW） |
| 打包 | NSIS (主) + MSI (可选) |
| 更新 | tauri-plugin-updater + GitHub Releases |

### 4.2 数据库 7 张表

| 表 | 用途 | 关键字段 |
|---|---|---|
| `settings` | KV 配置 | key, value |
| `passwords` | 加密密码 | id, title, username, encrypted, url, notes, use_count, last_used_at |
| `apps` | 已管理软件 | id, name, path, icon_path, category_id, use_count, last_used_at |
| `app_categories` | 软件分类 | id, name, icon, sort_order |
| `snippets` | 文本片段 | id, title, content, tags, use_count, last_used_at |
| `temp_contents` | 临时内容 | id, content, expire_at, created_at |
| `pinned_items` | 跨模块置顶 | id, ref_type, ref_id, sort_order |

### 4.3 关键模块

| 模块 | 文件 | 行数 | 职责 |
|---|---|---|---|
| `lib.rs` | src-tauri/src/lib.rs | ~1000 | Tauri commands 总入口 |
| `db.rs` | src-tauri/src/db.rs | ~600 | SQLite 封装 |
| `crypto.rs` | src-tauri/src/crypto.rs | ~150 | AES + Argon2 |
| `win_dock.rs` | src-tauri/src/win_dock.rs | ~500 | Win32 贴边隐藏子类化 |
| `win_launch.rs` | src-tauri/src/win_launch.rs | ~80 | ShellExecuteW 启动 |
| `MainLayout.vue` | src/components/MainLayout.vue | ~500 | 窗口主框架 |
| `widget.ts` | src/stores/widget.ts | ~400 | 窗口状态 store |

### 4.4 安全模型

- 主密码 → Argon2id 派生 32 字节密钥
- 字段级 AES-256-GCM 加密（每条独立 nonce）
- 内存密钥 5 分钟闲置清空（auto-lock）
- 剪贴板复制后 15s 比对清空（避免破坏用户后续复制）
- 恢复短语：12 词 BIP39，加密存盘

## 5. 发布策略

### 5.1 定价模型（v1.0 双层）

| 维度 | 免费版 | 完整版（¥9.9 买断） |
|---|---|---|
| 密码 | 10 条 | 不限 |
| 软件 | 10 个 | 不限 |
| 片段 | 5 条 | 不限 |
| 临时 | 不限 | 不限 |
| 全部 v1.x 升级 | ✅ | ✅ |
| 激活方式 | 默认 | 输入激活码（一次） |

### 5.2 激活码方案（v1.0 简化版）

- 方案 A：**软激活** — 启动时不验证，纯靠用户自觉（不推荐，长期会被白嫖）
- 方案 B：**离线激活码** — 用户邮箱 → 我们生成 → 写入本地 settings（推荐）
- 方案 C：**联网验证** — 启动时联网校（最严但违背本地优先原则，v1.0 不做）

> v1.0 暂定方案 B 简化版：**首次启动显示"解锁完整版"按钮，点击后让用户输入 12 位激活码，本地校验格式（不需要真验证），导入 settings.activated=true**。等你真正开始收钱再做真校验。

### 5.3 分发渠道

| 渠道 | 优先级 | 备注 |
|---|---|---|
| **GitHub Releases** | 🥇 P0 | 免费、自动更新 |
| **官网** | 🥈 P1 | 简单的着陆页，下载跳转 GitHub |
| **微软商店** | 🥉 P2 | 需 ¥600+ 开发者认证，v1.0 跳过 |
| **国内网盘分发** | 跳过 | 容易丢信任 |

## 6. 里程碑

### 6.1 v1.0 上线（4 周冲刺）

| 周 | 任务 |
|---|---|
| **W1** | 补 P0 bug（DB schema 缺字段 / 剪贴板 / Win32 子类化） + 打包配置（图标/headerImage/CSP） |
| **W2** | GitHub Actions 自动打包 + 首次启动引导 + 卸载验证 |
| **W3** | README + 9.9 激活码 + 限制数量逻辑 |
| **W4** | Release v1.0.0（公开测试） → 收反馈 → 修一波 → Release v1.0.1 正式版 |

### 6.2 v1.x 维护期

- 修 P0/P1 bug
- 性能优化（启动速度、扫描速度）
- 小功能：自定义分类、导入/导出、深色模式微调

### 6.3 v2.0 大版本（3-6 月后）

- 全局命令面板（Ctrl+Space）
- 端到端加密云同步（WebDAV）
- AI 扩展（v2.1 之后）
- 独立"清理"产品（v2.5 之后单独发布）
