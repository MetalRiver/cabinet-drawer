## ✨ 产品简介
**抽屉柜 Drawer** — 您的私密桌面收纳箱！
一个轻量级、安全的桌面助手，帮你把常用的软件、网址、密码、临时文件、剪贴板，像塞进抽屉一样整理好，主密码加密锁屏保护隐私。

---

### 🎯 核心功能
| 功能模块 | 说明 |
| :--- | :--- |
| 🗂️ **应用管理** | 一键分类管理「应用程序 / 网址URL / 文件夹」，点击即开，智能判断类型不混淆 |
| 🔐 **密码管理** | 本地加密存储（AES-256-GCM，主密码经 Argon2 派生数据密钥），主密码锁屏防窥视 |
| 🗑️ **回收站机制** | 误删不担心，随时恢复或永久删除 |
| 🗒️ **剪贴板碎片** | 一键保存常用文字片段，快速复制不重复输入 |
| 📁 **临时文件收纳** | 把乱七八糟的临时文件放进来，统一管理，过期清理 |
| 🔒 **主密码锁屏** | 离开电脑一键锁屏，所有数据加密保护 |
| 📌 **贴边隐藏** | 窗口拖到屏幕边缘自动隐藏，鼠标滑过立刻弹出，不占桌面空间 |
| 🟢 **系统托盘** | 后台运行不占任务栏，托盘图标快速操作 |

---

### 🛠️ 技术栈
- **前端框架**：Vue 3 + TypeScript + Pinia + Vue Router
- **桌面框架**：Tauri 2（Rust 后端，体积超小，内存占用极低）
- **本地数据库**：SQLite（单文件，所有数据只存你本地，不上传任何服务器！）
- **加密算法**：AES-256（主密码加密保护敏感数据）
- **打包体积**：NSIS 安装包 **4.7 MB**，绿色单文件 **7.7 MB**

---

### 📥 下载安装（Windows 10/11 64位）
1. 下载本页面附件：`抽屉柜 Drawer_0.3.1_x64-setup.exe`（4.7MB）
2. 双击运行安装向导，一路下一步即可（支持自动创建开始菜单 + 桌面图标）
3. 首次运行会引导设置「主密码」，并生成 12 个恢复短语——主密码要记好，恢复短语请抄在纸上保存（忘记主密码时可凭它重置）
4. 开始使用！所有数据存在你本地电脑，绝对隐私 🔒

> ⚠️ 首次启动时 Windows Defender / 杀毒软件可能误报，点「仍要运行」即可（Tauri 新应用签名问题，保证无毒无后门）
